# Welcome to lazymark

lazymark keeps your notes as plain markdown files in one folder. Edit them with any editor; lazymark never locks or rewrites a note you did not touch.

Press `?` at any time to see the keys for the panel you are in.

- [x] Install lazymark
- [ ] Create your first note with `c`
- [ ] Try the Kanban board with `W`
